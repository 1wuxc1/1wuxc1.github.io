同步电机基本介绍

一、基本定义

同步电机是一种交流电机，其稳态运行时，转子的转速 nnn 与电网频率 fff、极对数 ppp之间保持严格不变的关系：n=60fp(转/分钟) n = \frac{60f}{p} \quad (\text{转/分钟}) n=p60f​(转/分钟)
无论负载如何变化（在允许范围内），这个转速都恒定不变。

二、基本结构

同步电机由两大部分组成：

  1. 定子（电枢）

    • 结构与异步电机定子基本相同，由硅钢片叠压而成，槽内嵌有三相对称绕组。
    • 接通交流电后，定子会通入三相电流，产生一个旋转的磁场。

  2. 转子（磁极）

    • 作用是产生一个恒定的主磁场，这是同步电机区别于异步电机的关键。主要有两种类型：

      • 电励磁型：转子上绕有励磁绕组，通入直流电产生磁场。这是传统同步发电机和大功率电动机的主流形式。
      • 永磁型：转子上安装永久磁铁，无需外部励磁，结构更简单，效率和功率密度更高，常见于现代伺服电机、电动汽车驱动电机。

    • 根据转子结构，电励磁转子又分为：

      • 隐极式：转子呈圆柱形，气隙均匀，机械强度高，适用于高速旋转，如火电厂的汽轮发电机（通常为2极，3000转/分）。
      • 凸极式：磁极明显凸出，气隙不均匀，适合中低速运行，如水轮发电机、大功率同步电动机。

三、工作原理

  1. 定子旋转磁场：定子三相绕组通入对称交流电后，会合成一个在空间旋转的磁场，转速为同步转速 n0n_0n0​。
  2. 磁场相互作用：转子通入直流励磁后，变成一个电磁铁，产生恒定的南北极。定子旋转磁场的磁极会与转子磁极产生磁拉力。
  3. 同步旋转：就像两块磁铁一样，旋转的定子磁极拉着转子磁极一起同步旋转。转子因此被拖着以同步转速转动，故称“同步电机”。

四、主要分类

  • 按用途：

    • 同步发电机：将机械能转换为电能，是全世界发电的主力。
    • 同步电动机：将电能转换为机械能，用于不调速的大功率恒速驱动或需要高精度控制的场合。
    • 同步调相机：一种空载运行的同步电机，专门向电网吸收或发出无功功率，用来调节电网的功率因数和稳定电压。

  • 按转子结构：隐极式（高速）、凸极式（低速）。

  • 按励磁方式：电励磁、永磁、混合励磁等。

五、核心运行特性（以电动机为例）

  • 绝对硬机械特性：转速绝对恒定，不随负载变化，这是其作为恒速驱动（如大型压缩机、鼓风机）的最大优势。
  • 功率因数可调：这是同步电机最宝贵的特性。通过调节转子的直流励磁电流，可以改变电机向电网吸收或发出无功功率的性质。
    • 正常励磁：功率因数为1，只从电网吸收有功功率。
    • 过励磁：电机呈容性负载，向电网发出无功功率，可用于改善工厂的功率因数。
    • 欠励磁：电机呈感性负载，从电网吸收无功功率。
  • 功角特性与稳定性：同步电机的电磁功率 PPP 与功角 δ\deltaδ （转子磁场与定子合成磁场之间的夹角）的正弦成正比 P∝sin⁡δP \propto \sin\deltaP∝sinδ。负载增大时，功角 δ\deltaδ 会增大，以输出更大的电磁转矩。但若过载导致 δ>90∘\delta > 90^\circδ>90∘，电机会失步而停转。

负载情况下的电枢反应

一、前提条件

  • 电枢电流 Ia≠0I_a \neq 0Ia​=0，电机带载运行。
  • 同步转速 ns≠0n_s \neq 0ns​=0，转子与旋转磁场同步。
  • 气隙磁场由 主极磁场（永磁体产生）与 电枢磁场（负载电流产生）合成。

二、电枢反应的定义

电枢反应：电枢电流产生的电枢磁场对主极磁场的影响，使合成气隙磁场的大小和分布发生变化。

三、决定电枢反应性质的夹角

电枢反应的性质（增磁、去磁、交磁）完全取决于 空载反电动势 E0\boldsymbol{E_0}E0​ 与电枢电流 Ia\boldsymbol{I_a}Ia​ 之间的相位差角 ψ\boldsymbol{\psi}ψ（内功率因数角）。

  • ψ\psiψ 定义为 I⃗a\vec{I}_aIa​ 滞后 E⃗0\vec{E}_0E0​ 的角度。
  • 以 E⃗0\vec{E}_0E0​ 为参考相位（d 轴正方向），将 I⃗a\vec{I}_aIa​ 分解：
    • 直轴分量 Id=−Iasin⁡ψI_d = -I_a \sin\psiId​=−Ia​sinψ（负号表示滞后时 Id<0I_d<0Id​<0，为去磁；超前时 Id>0I_d>0Id​>0，为增磁）
    • 交轴分量 Iq=Iacos⁡ψI_q = I_a \cos\psiIq​=Ia​cosψ

四、不同 ψ\psiψ 角对应的电枢反应

1. ψ=0∘\psi = 0^\circψ=0∘（IaI_aIa​ 与 E0E_0E0​ 同相）

  • Id=0I_d = 0Id​=0，Iq=IaI_q = I_aIq​=Ia​
  • 纯交轴电枢反应（交磁）：电枢磁动势正交于主极磁动势，使合成磁场轴线扭歪一个角度，产生最大转矩。
  • 合成磁通幅值基本不变（表贴式电机）或略有变化（内置式 Lq≠LdL_q \neq L_dLq​=Ld​）。

2. 0∘<ψ<90∘0^\circ < \psi < 90^\circ0∘<ψ<90∘（电流滞后 E0E_0E0​）

  • Id<0I_d < 0Id​<0，Iq>0I_q > 0Iq​>0
  • 直轴去磁＋交轴交磁：电枢反应同时存在去磁分量和产生转矩的交轴分量。
  • 直轴去磁作用使合成气隙磁通减弱，电机反电动势降低，适用于弱磁扩速工况。

3. ψ=90∘\psi = 90^\circψ=90∘（电流滞后 E0E_0E0​ 90°）

  • Id=−IaI_d = -I_aId​=−Ia​，Iq=0I_q = 0Iq​=0
  • 纯直轴去磁反应：全部电枢电流用于削弱主极磁场，合成磁通显著减小。
  • 此时电磁转矩中永磁转矩为零（Tm∝ψfIqT_m \propto \psi_f I_qTm​∝ψf​Iq​），仅可能存磁阻转矩（若 Ld≠LqL_d \neq L_qLd​=Lq​）。

4. −90∘<ψ<0∘-90^\circ < \psi < 0^\circ−90∘<ψ<0∘（电流超前 E0E_0E0​）

  • Id>0I_d > 0Id​>0，Iq>0I_q > 0Iq​>0
  • 直轴增磁＋交轴交磁：直轴电枢反应起到增磁作用，合成磁场增强。
  • 可提高铁心利用率，增加转矩输出，但需注意磁路饱和限制及永磁体退磁风险。

五、矢量关系总结

在转子 dq 坐标系下，合成气隙磁链 ψ⃗δ\vec{\psi}_\deltaψ​δ​ 可表示为：

ψ⃗δ=ψ⃗f+LdId+jLqIq\vec{\psi}_\delta = \vec{\psi}_f + L_d I_d + j L_q I_q ψ​δ​=ψ​f​+Ld​Id​+jLq​Iq​

  • ψ⃗f\vec{\psi}_fψ​f​ 为主极磁链（与 E⃗0\vec{E}_0E0​ 垂直，相位滞后 E⃗0\vec{E}_0E0​ 90°）。
  • IdI_dId​ 直接改变 ψf\psi_fψf​ 同轴向上的磁链大小（增磁/去磁）。
  • IqI_qIq​ 产生正交磁链，使合成磁链矢量发生相位偏移，形成转矩。

六、结论

电枢反应的性质完全由 E0\boldsymbol{E_0}E0​ 与 Ia\boldsymbol{I_a}Ia​ 的夹角 ψ\boldsymbol{\psi}ψ 控制：

  • 交轴分量 决定转矩大小。
  • 直轴分量 决定磁场的增减（去磁或增磁）。

同步电抗(一相的电抗，不是3相抽象出来的)

同步电抗”是交流同步电机（如永磁同步电机 PMSM 或无刷直流电机 BLDC）在同步转速下运行时，定子（电枢）绕组表现出的等效交流阻抗的核心部分。为了从工程本质上理解它，我们可以将其拆解为两个物理过程：

Xs=Xa+XσX_s = X_a + X_\sigma Xs​=Xa​+Xσ​

电枢反应电抗 (XaX_aXa​)： 当定子绕组通入三相交流电时，会产生一个旋转磁场。这个磁场必然会跨过气隙，与转子永磁体（或励磁绕组）产生的磁场发生相互作用，从而改变气隙主磁场的分布和大小。这种“定子电流产生的磁场对主磁场的反作用”（即电枢反应），在电路等效模型中就被抽象为一个电抗。

漏电抗 (XσX_\sigmaXσ​)： 定子电流产生的部分磁力线没有跨过气隙进入转子参与机电能量转换，而是仅在定子齿槽或绕组端部闭合。这部分漏磁通产生的电抗就是漏电抗。

  • 物理映射： 对应刚才图表最右侧的汇聚点 EEE（实际工程中还需减去电阻压降，即为 U˙\dot{U}U˙）。
  • 连结理解： 这是用示波器或万用表真正在电机三相接线柱上测量到的电压，也是变频器/驱动器最终输出给电机的 PWM 合成电压基波。

3. I˙aRa\dot{I}_a R_aI˙a​Ra​（定子电阻压降） —— 无法避免的纯热耗散

  • 物理映射： 不涉及跨气隙的磁场转换，纯粹是定子铜线材质带来的物理阻碍。
  • 连结理解： 这一项是实数项（与电流同相）。它不参与任何磁场造磁，只负责发热（铜损 I2RI^2RI2R）。在高速运转时它微不足道，但在低速大扭矩（甚至堵转）时，它成为了限制电流环的最核心要素。

  • 物理映射： 对应第二、三条链路的合并：E˙a\dot{E}_aE˙a​（电枢反应） + E˙σ\dot{E}_\sigmaE˙σ​（定子漏磁）。
