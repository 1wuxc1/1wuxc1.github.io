电势的判断


如图 现在有电荷4c，从a->b需要8焦耳，b->c需要12焦耳。那么abc三点电势为多少。

图1中，b点为接地处。b = 0。b->c需要12J。那么c点电势其实为Vc=−12/4=−3V_c = -12/4=-3Vc​=−12/4=−3。a->b需要8焦耳，a点为Va=8/4=2V_a = 8/4=2Va​=8/4=2。

图2中，c点为接地处。b = 0。b->c需要12J。那么c点电势其实为Vb=12/4=3V_b = 12/4=3Vb​=12/4=3。a->b需要8焦耳，所以a->c点需要20J，a点为Va=20/4=5V_a = 20/4=5Va​=20/4=5。

功率方向判断


计算电路中各元件吸收或产生的功率，核心原则是：计算功率时，通常设电压和电流为关联参考方向，公式为 P=UIP = UIP=UI。如果算出的 P>0P > 0P>0，表示元件吸收功率；如果 P<0P < 0P<0，表示元件产生功率（产生功率的数值等于 ∣P∣|P|∣P∣）。

所谓“关联参考方向”，就是电流 III 从电压 UUU 的“+”极流入，“-”极流出。如果是非关联方向，则 P=−UIP = -UIP=−UI。

下面为你详细拆解计算步骤：

第一步：确定各元件上的电流方向和大小

根据图中的红色箭头和节点（基尔霍夫电流定律 KCL）进行推导：

  • 方框2：左侧支路电流为 I1=2AI_1 = 2\text{A}I1​=2A，方向向下。所以流过方框2的电流是 2A2\text{A}2A，方向向下。
  • 方框1：电流 I1I_1I1​ 在左侧从上往下流，说明它必然是从方框1流过来，再往下走。因此流过方框1的电流也是 I1=2AI_1 = 2\text{A}I1​=2A，方向向左。
  • 方框3：左下方节点没有其他支路，电流 I1I_1I1​ 向下流经过方框2后，必然向右流经过方框3。所以流过方框3的电流为 I1=2AI_1 = 2\text{A}I1​=2A，方向向右。
  • 方框4：中间支路电流已知为 I2=1AI_2 = 1\text{A}I2​=1A，方向向上。
  • 方框5：右侧支路电流已知为 I3=−1AI_3 = -1\text{A}I3​=−1A，方向标注为向下（即实际电流大小为 1A1\text{A}1A，方向向上）。
  • 方框6：看上方中间的节点。流入该节点的电流是 I2I_2I2​ (向上，1A1\text{A}1A)，流出该节点的电流是向左的 I1I_1I1​ (2A2\text{A}2A)。设向右流过方框6的电流为 I6I_6I6​。根据 KCL（流入 = 流出）：I2=I1+I6I_2 = I_1 + I_6I2​=I1​+I6​，即 1=2+I61 = 2 + I_61=2+I6​，解得 I6=−1AI_6 = -1\text{A}I6​=−1A。这意味着流过方框6的实际电流是 1A1\text{A}1A，方向向左。

第二步：逐个计算各元件的功率

1. 方框1

  • 电压：U1=1VU_1 = 1\text{V}U1​=1V，极性为左“+”、右“-”。
  • 电流：2A2\text{A}2A，方向向左（从“+”极流出，从“-”极流入，非关联方向）。
  • 功率：P1=−U1×I1=−1V×2A=−2WP_1 = - U_1 \times I_1 = -1\text{V} \times 2\text{A} = -2\text{W}P1​=−U1​×I1​=−1V×2A=−2W。
  • 结论：方框1产生 2W 功率。

2. 方框2

  • 电压：U2=−3VU_2 = -3\text{V}U2​=−3V，极性为上“+”、下“-”。
  • 电流：2A2\text{A}2A，方向向下（从“+”极流入，关联方向）。
  • 功率：P2=U2×I1=−3V×2A=−6WP_2 = U_2 \times I_1 = -3\text{V} \times 2\text{A} = -6\text{W}P2​=U2​×I1​=−3V×2A=−6W。
  • 结论：方框2产生 6W 功率。

3. 方框3

  • 电压：U3=8VU_3 = 8\text{V}U3​=8V，极性为左“+”、右“-”。
  • 电流：2A2\text{A}2A，方向向右（从“+”极流入，关联方向）。
  • 功率：P3=U3×I1=8V×2A=16WP_3 = U_3 \times I_1 = 8\text{V} \times 2\text{A} = 16\text{W}P3​=U3​×I1​=8V×2A=16W。
  • 结论：方框3吸收 16W 功率。

4. 方框4

  • 电压：U4=−4VU_4 = -4\text{V}U4​=−4V，极性为下“+”、上“-”。
  • 电流：I2=1AI_2 = 1\text{A}I2​=1A，方向向上（从“+”极流入，关联方向）。
  • 功率：P4=U4×I2=−4V×1A=−4WP_4 = U_4 \times I_2 = -4\text{V} \times 1\text{A} = -4\text{W}P4​=U4​×I2​=−4V×1A=−4W。
  • 结论：方框4产生 4W 功率。

5. 方框5

  • 电压：U5=7VU_5 = 7\text{V}U5​=7V，极性为上“+”、下“-”。
  • 电流：I3=−1AI_3 = -1\text{A}I3​=−1A，方向向下（从“+”极流入，关联方向）。
  • 功率：P5=U5×I3=7V×(−1)A=−7WP_5 = U_5 \times I_3 = 7\text{V} \times (-1)\text{A} = -7\text{W}P5​=U5​×I3​=7V×(−1)A=−7W。
  • 结论：方框5产生 7W 功率。

6. 方框6

  • 电压：U6=−3VU_6 = -3\text{V}U6​=−3V，极性为左“+”、右“-”。
  • 电流：我们求得流过它的电流为 −1A-1\text{A}−1A，方向向右（从“+”极流入，从“-”极流出，关联方向）。
  • 功率：P6=−U6×I实际=(−3V)×(−1A)=3WP_6 = - U_6 \times I_{实际} = (-3\text{V}) \times (-1\text{A}) = 3\text{W}P6​=−U6​×I实际​=(−3V)×(−1A)=3W。 (或者用定义：设向右为 I6=−1AI_6=-1\text{A}I6​=−1A，则 P=U6I6=(−3)(−1)=3WP=U_6 I_6 = (-3)(-1)=3\text{W}P=U6​I6​=(−3)(−1)=3W)
  • 结论：方框6吸收 3W 功率。

总结与验证

  • 吸收功率的元件：方框3（16W）、方框6（3W）。总计吸收：16+3=19W16 + 3 = 19\text{W}16+3=19W。
  • 产生功率的元件：方框1（2W）、方框2（6W）、方框4（4W）、方框5（7W）。总计产生：2+6+4+7=19W2 + 6 + 4 + 7 = 19\text{W}2+6+4+7=19W。

功率平衡（吸收 = 产生），证明计算结果完全正确。
